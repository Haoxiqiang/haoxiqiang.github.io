Source code: [haoxiqiang-template](https://github.com/Haoxiqiang/haoxiqiang-template)

## Jekyll Overview

[Jekyll](https://jekyllrb.com/) is a static site generator that converts plain text (Markdown, Liquid templates) into a complete static website without requiring a database. Combined with [GitHub Pages](https://pages.github.com/), it provides free blog hosting.

## Features

### Code Highlighting

Jekyll has built-in syntax highlighting powered by Rouge:

```ruby
def print_hi(name)
  puts "Hi, #{name}"
end
print_hi('Tom')
#=> prints 'Hi, Tom'
```

### LaTeX Math Rendering

Set `latex: true` in the page front matter to enable MathJax rendering:

$$
\begin{aligned} \dot{x} &= \sigma(y-x) \\
\dot{y} &= \rho x - y - xz \\
\dot{z} &= -\beta z + xy \end{aligned}
$$

$$
a^2 + b^2 = c^2
$$

When $a \ne 0$, there are two solutions to $ax^2 + bx + c = 0$.

### Excerpt Separator

Use `<!--more-->` to mark the split point between the article summary and the full content.
